# 座位游戏机器人牌力策略

2026-11-06，用户确认德州、炸金花、棋牌牛牛、二十一点、十三水、三公暗一、麻将可根据真人已发手牌制定策略。权限只供服务端机器人计算；客户端、旁观、回顾、公正码和原发牌/结算规则仍遵守各自授权。百人玩法不在此次范围。

各游戏 robot.js 只维护玩法策略，公共入离桌、带入、模拟余额及冷却继续复用 core/robot.js 与 SeatGame。所有动作走现有校验、扣款、广播和结算入口。core/robot-cards.js 为牛牛和三公提供独立未知牌采样：排除本人可见牌及真人已知牌，其他机器人牌为未知，最多 64 次；当前普通牛牛/三公各 48 次，七癞牛牛 16 次。缓存按牌局弱引用及本人、对手牌值区分，结束后可回收，不接收引擎牌序。模块沿现有 rel 版本化依赖热更新，不需要重启服务。

| 游戏 | 决策依据及调整 |
| --- | --- |
| 德州 | 双方牌力、听牌、多人胜率、底池价格、筹码、位置，区分价值进攻、慢打、半诈唬和弃牌；真人底牌固定参与采样，未来公共牌独立生成。 |
| 炸金花 | 按花色比及 A23 规则比较真人牌；本人未看全时只用已展示牌；评估看牌成本、短筹码边池、比牌目标、加注压力和少量诈唬。 |
| 棋牌牛牛 | 本人仅用零/三/四张已展示牌，按真实牛牛/七癞分类及赢输倍率评估抢庄和闲家下注；下注只针对实际庄家胜负，已知其他真人牌从采样中排除。配置的真人自动策略仍优先，不扩大托管真人的手牌权限。 |
| 三公暗一 | 本人只用前两张，暗第三张独立采样；逐一评估合法倍率，复用 scoring.payouts 的分层领取上限、豹子喜钱及税费，结合本金控制风险。未提交的对手下注以保守默认量估算，已提交时使用真实下注。 |
| 十三水 | 机器人最多比较十二组合法建议，对真人已提交摆法或前三组建议评估平均及较差情况下的收益；复用结算的纯分墩/打枪/马牌比较，选摆法不改变任何已发原牌或真人提交。不推断未提交的真人最终选择；机器人评估未包含未知机器人对手或完整全垒打场景的最优搜索。 |
| 二十一点 | 玩家牌本来公开，按六副牌减去本局可见牌估算频率；递归比较要牌/停牌/加倍/分牌收益，计入五小龙和 3:2、分牌非黑杰克、庄家软 17 停牌。模型使用固定频率近似，不读取隐藏庄家牌或剩余牌靴；庄家规则固定，不针对真人改动。 |
| 麻将 | 极速、长沙、红中血流共用策略；按牌组分解效率选换牌/定缺，按有效活张和真人威胁选弃牌/报听，避免有明确点炮或抢杠风险的动作，比较吃碰后的结构。直接胡牌优先，定缺、已听摸打、血流点炮门槛及锁手照常校验。 |

算法是有计算上限的规则及期望收益策略，不是完整求解器。知道真人手牌带来信息优势，但不控制胜负；功能测试的混合对局不能作为真人长期胜率或高水平评级。牛牛自身末张、三公自身第三张、其他机器人暗牌及未来公共牌/牌墙/牌靴保持未知，客户端遮罩不改变。

测试在 test/game-server/games/各游戏/robot.test.js 及 test/game-server/core/robot-cards.test.js。覆盖相同本人牌随真人牌变化作出不同决策、未知牌排除与缓存失效、隐藏字段访问拒绝、合法动作金额、多玩法混合对局、真实结算及筹码守恒；二十一点把 houseNetScore 纳入对账。使用 npm test 执行全量回归。
