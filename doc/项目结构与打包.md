# 项目结构与打包

## 目录职责

| 目录 | 职责 | 生产包 |
| --- | --- | --- |
| hall/、game-server/、match/、client-web/ | 服务源代码及配置 | 保留 |
| shared/ | 正式 RPC 门面、生产实现与协议 | 保留 |
| static/ | 原始客户端、大厅和头像资源 | 保留，不修改 |
| test/ | 自动化测试，按服务归类；browser/ 为浏览器回归工具 | 排除 |
| cache/ | 开发用内存模拟、种子、钱包、回顾接口及页面补丁 | 排除 |
| scripts/ | build-prod.js 构建；prod.js 生产启动 | 只保留 prod.js |
| doc/、tools/ | 文档和开发分析工具 | 排除 |

## 本地开发与测试

要求 Node.js 22.20 或更高版本；所有依赖仍安装在根目录。

~~~sh
npm install
npm run dev
npm test
npm test --workspace=game-server
~~~

test/run.js 递归发现测试文件，新增测试不必修改命令。生产业务不能静态依赖 cache，RpcAdapter 的同步接口在 dev 分支才加载本地类。服务启动器监听对应的本地页面补丁和回顾实现，业务热更新不清除常驻房间和余额状态。

## 生产构建与部署

~~~sh
npm run build:prod
cd dist/production
npm ci --omit=dev
npm run hall
npm run game-server
npm run match
npm run client-web
~~~

四个服务由进程管理器分别启动。构建包含 static，过滤 .git、日志、临时文件和任何测试文件。test/、cache/、mock-server/、tools/、doc/、node_modules 不进入产物。build-manifest.json 列出产物文件；重复构建仅覆盖由本构建器生成的 dist/production，不删除源文件。

构建只改变产物内 YAML：env 设 prod，wallet.mode 设 online，删除 local_balance。其他连接配置沿用源配置，部署前按实际环境设置，也可通过启动参数 --config 指定配置文件。生产启动器强制 GOGAME_ENV=prod、IS_DEV=0，避免仍走内存模拟。根目录也可使用 npm run prod:hall 等对应命令。

正式房间、排名、旁观状态和 Redis 回顾缓存属于生产逻辑，不放 cache。生产牌局回顾继续走 data-center；此次整理不新增尚未接通的生产回顾协议。

.npmignore、.dockerignore、.gitattributes 也排除 test/cache，但它们不能替代生产环境配置转换；正式部署使用 build:prod 的产物。测试和本地实现仍提交 Git。

## 验证

全量测试覆盖迁移前的玩法、协议、钱包及房间生命周期。结构测试构建一个没有 test/cache 的实际副本，验证生产 RPC/游戏/大厅/客户端模块加载、未注入本地页面补丁，以及生产环境不会回退模拟钱包；不连接真实数据库或重启常驻服务。
