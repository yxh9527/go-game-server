# 热更新参数求值与局部作用域修复

本轮开始核验，上一批非德州净盈利局数／胜率后端 2 文件已全部应用，0 待应用。本轮只修改 Node 热加载转换器和测试，不新增后端包。

## 修复

旧转换器把静态 rel(import.meta.url, spec, version) 整个调用替换成固定 URL 的 import()，跳过原参数表达式。如果版本或额外参数包含自增、赋值、异步等待或抛错，热更新前后的代码行为会不同。

现在固定依赖 URL 的同时，按原顺序执行各参数表达式，再调用 import()；原同步异常继续向调用者抛出，原 await 继续等待，不跳过这些表达式。旧处理器仍绑定旧内容版本，新处理器加载新版本，不因本次修正切换旧请求的依赖。

补齐命名 class 和 switch 分支的局部声明作用域识别。同名局部 rel、函数参数、var 声明、块级声明、catch 参数和 for 声明不作为仓库导入函数转换；补丁字符串及注释不改。

动态依赖辅助代码不再插到文件开头的 hashbang 之前，保留原脚本头的语法位置。动态字面量依赖集合继续在加载时绑定内容版本，旧延迟调用在真实源文件变化后仍取原依赖。

## 剩余边界

本轮修正热加载转换语义，不等同于 Node 旧 ESM 模块已可完整卸载。仍由旧请求、房间、定时器或模块运行时持有的引用不能直接清空；持续真实源码变化的长期内存压测和完整运行时回收仍需继续。
