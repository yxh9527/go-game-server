# 常规21点大厅消息协议

## 1. 协议概览

本日志记录常规 21 点大厅启动及房间配置查询。入口 URL 路径为 `/31/0/`，当前仅覆盖大厅初始化和房间列表，没有进入具体牌桌。

| 项目 | 内容 |
| --- | --- |
| 游戏名称 | 赌场21点 |
| `gameType` | `31` |
| `playMode` | `0` |
| `roomType` | `31` |
| 房间配置接口 | `GET /internal/v1/do`，`op=38` |
| 房间配置数量 | 4 档 |
| 响应状态 | `msgCode=200` |
| 日志入口 | `https://lb.boyuee.top/31/0/` |

日志里没有 MQTT `PUBLISH` 业务消息，也没有记录具体游戏房间的 RoomSocket 操作消息。

## 2. 页面入口

```text
https://lb.boyuee.top/31/0/?userToken=...&userId=...&clubId=...&openId=...&gameIp=...&v=...&channel=...&plat=...&language=...&currency=...
```

关键路径参数：

| 路径段 | 值 | 含义 |
| --- | ---: | --- |
| `gameType` | `31` | 赌场21点 |
| `playMode` | `0` | 常规玩法 |

## 3. 大厅初始化请求

日志在加载大厅时发出以下请求：

| 操作 | 解码后的参数 | 响应数据摘要 |
| --- | --- | --- |
| `op=54` | `op=54` | `ticketNums=0`，`walletAmount=1973423` |
| `op=53` | 自动/API 登录信息及用户、俱乐部、平台、语言、货币等参数 | 返回大厅、用户和登录配置 |
| `op=8165` | `uid=2223152&clubId=125566&isNew=true&op=8165` | 返回玩家及俱乐部资料 |
| `op=62` | `op=62` | `data=[]` |

这些请求属于大厅初始化或用户信息查询，不是 21 点牌桌操作协议。

## 4. 房间配置请求

请求接口：

```text
GET /internal/v1/do
```

`op=38` 的 `param` Base64 解码后为：

```text
gameType=31&roomClassifications=&playMode=0&op=38
```

请求 URL 还携带用户 token、`userId` 和 `clubId` 等公共参数。

## 5. 房间配置响应

```json
{
  "msgCode": 200,
  "errMsg": null,
  "data": [
    {
      "gameType": 31,
      "roomClassifications": [],
      "roomInfoData": []
    }
  ]
}
```

本次 `roomInfoData` 返回 4 个常规玩法房间配置。

## 8. 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `gameType` | number | 游戏类型，赌场21点为 `31` |
| `roomType` | number | 房间类型，本次为 `31` |
| `gameRoomConfigId` | number | 房间配置编号 |
| `totalPeople` | number | 当前房间人数 |
| `playMode` | number | 玩法模式，本次为常规模式 `0` |
| `roomClassification` | number | 房间分类编号 |
| `ante` | number | 房间底注，本次分别为 `100`、`500`、`2000`、`10000` |
| `carryMin` | number | 最低携带金额 |
| `key` | string | 房间配置组合键 |
| `forceShowCard` | boolean | 是否强制显示牌面，本次为 `false` |
| `gameStatus` | number | 房间状态，大厅配置中为 `0` |
| `roomId` | number | 房间实例编号，列表配置中为 `0` |

其他配置字段与前述房间对象示例一致。本次 `seatInfoList`、`winStreakList`、`scoreMode`、`aofBet`、`waysJson`、`extendInfo`、`vipTableData`、`domain`、`serviceId`、`shield` 均为 `null`。

## 9. `key` 格式

```text
31/{playMode}/{ante}/{roomClassification}/{carryMin}
```

示例：

```text
31/0/500/2/2500
31/0/2000/4/10000
31/0/100/2/500
```

## 10. 通信流程与边界

1. 浏览器打开 `/31/0/`，进入赌场21点常规玩法大厅。
2. 大厅依次请求钱包、登录/大厅配置、玩家资料等初始化接口。
3. 大厅通过 HTTP `op=38` 查询 `gameType=31`、`playMode=0` 的房间配置。
4. 服务端返回 4 档房间配置，前端据此展示房间列表。
5. 本次日志未包含 MQTT 房间更新推送，也未包含进入具体牌桌后的 RoomSocket 游戏消息。
