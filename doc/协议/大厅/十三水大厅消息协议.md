# 十三水大厅消息协议

## 1. 概览

本日志记录十三水大厅切换和房间配置查询；没有进入牌桌，因此不包含摆牌、牌型比较、下注或结算等 RoomSocket 消息。

| 项目 | 内容 |
| --- | --- |
| 游戏 | Sss，十三水 |
| `gameType` / `subGameType` | `27` / `0` |
| `roomType` | `27` |
| 房间配置接口 | `GET /internal/v1/do`，`op=38` |
| 房间数量 | 8 |
| 响应 | `msgCode=200` |
| 客户端资源 | `sss` |

本次日志没有 MQTT 业务消息或游戏 WebSocket 消息。

## 2. 大厅切换

```json
{
  "type": "changeType",
  "value": {
    "gameType": 27,
    "subGameType": 0
  }
}
```

客户端预加载信息：`requestGameType=27`、`gameCfg=27`、`gameName=Sss`、资源包 `sss`。

## 3. 请求参数

接口：

```text
GET /internal/v1/do
```

`param` Base64 解码结果：

```text
gameType=27&roomClassifications=&op=38
```

公共 URL 参数：`userId=2223152`、`clubId=125566`。

## 4. 响应封装

```json
{
  "msgCode": 200,
  "errMsg": null,
  "data": [
    {
      "gameType": 27,
      "roomClassifications": [],
      "roomInfoData": []
    }
  ]
}
```

## 6. 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roomType` | number | 房间类型，十三水为 `27` |
| `gameRoomConfigId` | number | 房间配置唯一编号 |
| `totalPeople` | number | 当前房间人数 |
| `seatInfoList` | array/null | 座位信息；本次为 `null` |
| `winStreakList` | array/null | 连胜信息；本次为 `null` |
| `gameStatus` | number | 房间状态；大厅配置中为 `0` |
| `carryMin` | number | 最低携带金额 |
| `playMode` | number | 玩法模式编号；本次为 `0` 或 `1` |
| `roomClassification` | number | 房间分类；本次为 `2` 或 `4` |
| `ante` | number | 底注或基础下注金额 |
| `seeCardNo` | number | 看牌相关配置；本次为 `0` |
| `key` | string | 房间配置组合键 |
| `forceShowCard` | boolean | 是否强制显示牌面；本次为 `false` |
| `privateRoom` | boolean | 是否私人房间；本次为 `false` |
| `roomId` | number | 房间实例编号；大厅配置中为 `0` |

其余字段如 `dealerBgNo`、`lobbyThumbNo`、`gameStatusStartTime`、`gameStatusDuration`、`serverNow`、`roomIndex` 本次均为 `0`；`scoreMode`、`aofBet`、`waysJson`、`extendInfo`、`vipTableData`、`domain`、`serviceId`、`shield`、`seatInfoList`、`winStreakList` 为 `null`；`hundredGame`、`hundredMaxBet`、`hundredMinBet` 为 `0`，`openHundredGame`、`straddle` 为 `false`。

## 8. `key` 格式

```text
27/{playMode}/{ante}/{roomClassification}/{carryMin}
```

例如：`27/1/1/2/100`。分段依次是房间类型、玩法模式、底注、分类和最低携带金额。

## 9. 流程

1. 前端切换到 `gameType=27`、`subGameType=0`。
2. Cocos 客户端预加载 `sss` 资源。
3. 大厅通过 HTTP `op=38` 获取十三水房间配置。
4. 服务端返回 8 个 `roomType=27` 房间配置，前端据此刷新大厅列表。
5. 进入牌桌后才建立 RoomSocket；本次日志未覆盖该游戏阶段。
