# 德州-德州不秀牌大厅消息协议

## 1. 协议概览

本日志记录的是德州扑克“不秀牌”大厅的类型切换和房间配置查询。本次没有进入具体牌桌，因此没有采集到下注、发牌、结算等 RoomSocket 游戏消息。

| 项目 | 内容 |
| --- | --- |
| 游戏名称 | Holdem，德州不秀牌 |
| `gameType` | `19` |
| `subGameType` | `0` |
| 大厅接口 | `GET /internal/v1/do` |
| 房间配置操作 | `op=38` |
| `forceShowCard` 请求值 | `0` |
| 房间配置数量 | 6 个 |
| 响应状态 | `msgCode=200` |

## 2. 大厅切换消息

```json
{
  "type": "changeType",
  "value": {
    "gameType": 19,
    "subGameType": 0
  }
}
```

客户端收到消息后执行：

```text
preloadByChangeType
preloadGameSceneRes
gameCfg: 19
gameName: Holdem
bundle: gameHoldem
```

## 3. 房间配置请求

请求接口：

```text
GET /internal/v1/do
```

解码后的 `param` 参数：

```text
gameType=19&roomClassifications=&forceShowCard=0&op=38
```

请求 URL 中还携带：

```text
userId=2223152
clubId=125566
```

## 4. 房间配置响应

```json
{
  "msgCode": 200,
  "errMsg": null,
  "data": [
    {
      "gameType": 19,
      "roomClassifications": [],
      "roomInfoData": []
    }
  ]
}
```

本次响应中的 `roomInfoData` 包含 6 个房间配置。

## 6. 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roomType` | number | 房间类型，德州扑克为 `19` |
| `gameRoomConfigId` | number | 房间配置唯一编号 |
| `totalPeople` | number | 当前房间人数 |
| `seatInfoList` | array/null | 座位信息，本次大厅配置返回 `null` |
| `winStreakList` | array/null | 连胜信息，本次大厅配置返回 `null` |
| `gameStatus` | number | 房间状态，大厅配置中为 `0` |
| `smallBlind` | number | 小盲金额 |
| `bigBlind` | number | 大盲金额 |
| `straddle` | boolean | 是否开启 Straddle，本次全部为 `false` |
| `carryMin` | number | 最低携带金额 |
| `playMode` | number | 玩法模式编号，当前为 `0` 或 `2` |
| `roomClassification` | number | 房间分类编号，本次为 `2` |
| `ante` | number | 前注金额，本次为 `0` |
| `initialBet` | number | 初始下注金额，通常等于大盲金额 |
| `seeCardNo` | number | 看牌相关配置，本次为 `3` |
| `aofBet` | number/null | All-in or Fold 下注金额，本次为 `null` |
| `roomIndex` | number | 房间列表索引 |
| `privateRoom` | boolean | 是否私人房间，本次为 `false` |
| `roomId` | number | 房间实例编号，大厅配置中为 `0` |
| `forceShowCard` | boolean | 是否强制显示牌面，本次为 `false` |

## 8. `key` 字段格式

```text
19/{smallBlind}/{bigBlind}/{straddle}/{playMode}/{initialBet}/{roomClassification}/{carryMin}/{aofBet}/{forceShowCard}
```

本次不秀牌模式示例：

```text
19/10/20/false/0/20/2/500/0/false
```

与普通德州大厅相比，最后一段为 `false`，对应 `forceShowCard=false`。

## 9. 通信流程

1. 前端发送 `changeType`，切换到 `gameType=19`、`subGameType=0`。
2. Cocos 客户端预加载 `gameHoldem` 资源。
3. 大厅通过 HTTP `op=38` 请求德州不秀牌房间配置。
4. 请求参数携带 `forceShowCard=0`。
5. 服务端返回 6 个房间配置。
6. 前端根据 `roomInfoData` 刷新德州不秀牌房间列表。
7. 用户进入具体牌桌后，才会建立 RoomSocket，并使用独立的二进制游戏协议。
