## 字段和显示

| 字段 | 说明 |
| --- | --- |
| gameRoomConfigId / roomType / roomIndex / roomId | 与配置及真实运行房间匹配 |
| gameStatus | 保留该游戏现有状态枚举，不强行套用其他游戏 |
| gameStatusStartTime | 本次快照基准时刻，毫秒 |
| gameStatusDuration | 从基准时刻到真实阶段截止时刻的剩余毫秒数，最小 0 |
| serverNow | 与上述基准相同的服务器毫秒时间 |
| extendInfo | JSON 字符串，保持大厅的既有二次解析；包括公开牌面、局号、转盘及路单 |

显示倒计时为 ceil(max(0, start + duration - serverNow - 本地自收到该快照以来的时间) / 1000)。全列表共用一个时钟；刷新时重建时间基准，卸载后清理。正数倒计时耗尽后显示“状态同步中”，等待权威下一次状态，不自行猜测开奖结果或开始新局。

### 大厅牌面资源（2026-10-30）

/l01/img/cards/small/*.webp 与 Cocos bundle 是两套独立资源。日志中这些路径 404 时，先检查 static/hall/l01/img/cards/small；只同步 static/client/2.0.1279 无法补齐大厅图片。原版大厅预加载 0..54、60..72 的 68 张图片和 card-back-blue.png，共 69 个文件；编号 0 是有效牌，-1 是未公开牌，列表与原版回顾统一映射到蓝色牌背，不请求 -1.webp，不能将隐藏值替换成实际牌。

离线盘点：node scripts/sync-hall-card-assets.js --audit。缺失会列出具体文件并返回非零退出码。补齐：node scripts/sync-hall-card-assets.js --source https://lb.zhouerbao.top/，参数只接受公开大厅根地址，不传用户登录链接或 Cocos 版本目录。该工具仅下载原始图片，验证 PNG/WebP 格式、拒绝 HTML/截断内容、保留已有文件，支持断点后再次执行；报告打印实际绝对保存目录。下载失败不得声称图片已补齐。
