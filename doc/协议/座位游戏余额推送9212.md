# 座位游戏余额推送 9212

2026-11-20，影响 game-server 普通现金座位玩法，包括德州、炸金花、牛牛、十三水、麻将、二十一点及三公。

消息 GAME_POINT_UPDATE（9212）的 JSON 消息体为**数值积分余额**：

```json
100000
```

不能发送 `{"uid":42,"point":100000}`。当前原版 static/client/2.0.1279/assets/main/index.88f4e.js 的公共 updateGamePoint 处理函数直接把整条消息体保存到 walletAmount 和 clubData.walletAmount；公共余额模型也直接保存到 __usertBalancePoints。对象消息会将共用余额状态变成非数值，影响后续显示和金额校验。

余额使用原钱包账户积分，不改变带入额度或实际资金。带入／主动离桌、局后自动离桌和部分带出后的余额通知均采用该形状。赌场 LiveBlackJack 仍保留已有 seat-view 的可用账户／座位托管金额投影规则。

服务端已在具体发送点修复，不修改原静态客户端、不增加另一套消息字段。test/client-web/native-wallet-balance.test.js 从原 bundle 提取真实处理函数验证旧对象污染及数值消息恢复；重复入座／带入／离桌的协议回归验证实际推送为数值。
