
可确认：

- card 是打出的牌编码；

## 14. 结论

二人麻将与四人麻将共用一套 hzxl 消息协议，差异主要集中在房间配置和玩家数量：

~~~text
roomType=30 / hzxl
gameRoomConfigId=3002
maxPeople=2
gameStartNum=2
playMode=1

ROOM_LOGIN
 -> SEND_JOIN_ROOM(isOb=true, changeRoom=true)
 -> ROOM_TYPE_RESULT
 -> ROOM_INFO
 -> 3851
 -> 3859 / 3862 换三张
 -> 3860 / 3861 定缺
 -> 3852 / 3853 摸牌、出牌和响应
 -> 3853 type=3/7 副露或响应
 -> 3853 type=8 胡牌和实时积分
 -> 9212 / GAME_RECORD
 -> SEND_LEVEL_OUT / USER_LEVEL_ROOM
~~~

实现时应以 roomType=30、hzxl 和 gameRoomConfigId=3002 识别二人房间，以 currentInning 管理牌局，以两个 UID 管理玩家状态，并严格区分旁观可见的 cardLen、公开牌面和完整手牌。
