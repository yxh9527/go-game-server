| 6227 | MB_REGED_ROOM_INFOS | 多桌快照 |

| 6229 | MB_ROOM_BET_SETTLE | 中奖区结算 |
| 6207 | PLAYER_NUM_CHANGE | 人数变化 |
| 6106 | EXIT | 退出 |

## 5. 状态流程

~~~text
state=0 等待
 -> state=1 发牌和赔率
 -> state=2 下注
 -> state=4 开牌
 -> state=5 结算过渡
 -> state=6 统计/路单
 -> state=7 结束
~~~

6227/6228 的 totalBetsByArea 是七个下注区的累计下注，betAreaOdds 是本局赔率，winningAreas/lostAreas 是结算结果。

## 6. 注意事项

用户文件名“暗二”与日志 gameName“明三公牌”不一致。实现应以 roomType=50、playMode=2 和 hundredParams.gameName 为准，而不是只依赖文件名。

RoomSocket-111 的普通德州动作不能当作百人下注协议；本日志未给出百人下注请求的明确上行格式。

## 8. 结论

德州暗二日志实际对应 playMode=2 的明三公牌模式，协议主链为：

~~~text
ENTER -> 注册房间 -> 6227/6228
 -> 6212 发牌赔率
 -> 6229 中奖区和牌面结算
 -> 6204 路单 -> EXIT
~~~
