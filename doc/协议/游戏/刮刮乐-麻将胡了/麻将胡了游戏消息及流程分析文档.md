## 5. 一张彩票的消息时序

1. HTTP op=38 获取刮刮乐房间配置及 roomIndex。
2. HTTP op=45 获取 roomId，连接 RoomSocket-111。
3. ROOM_LOGIN 和 SEND_JOIN_ROOM 建立房间会话。
4. ROOM_TYPE_RESULT 确认服务端玩法为刮刮乐，gameRoomConfigId=6101。
5. 客户端发送 3702 空请求，服务端 3711 返回钱包、待处理票据、面额和倍数配置。
6. 客户端发送 3701，选择 revealMode、faceValue 和 kind。
7. 服务端 3713 返回票号、huMask、中奖金额、中奖等级及新余额。
8. 客户端可通过 6221 RETURN_100_RECORD 拉取该票历史记录。
9. 界面更新余额、刮开结果和累计中奖。

- 以 gameRoomId 和 serialFull 关联每一张票，不能仅按 roomType=61 合并流水。
- 购买请求应同时记录 faceValue、kind 和 revealMode。
- 只有服务端 3713 code=0 后才更新钱包和票面结果。
- huMask 长度为 20；保留原始整数编码，图标映射需查客户端资源或枚举。
- multiplier、winAmount、prizeTier 和 huCount 均采用服务端结果，不在前端重新计算。
- pendingTickets 非空时应先恢复未完成票据，避免丢失揭晓结果。
- 3701、3702、3711、3713 的日志名显示 undefined，消息编号和字段是当前可确认的协议依据。
