## 5. 游戏流程

### 5.1 摆牌

每位玩家把 13 张牌分成：

- 头墩：3 张。
- 中墩：5 张。
- 尾墩：5 张。

摆牌状态示例：

```json
{
  "uid": "<uid>",
  "hasArranged": true,
  "arrangedLastTime": 0,
  "arrangedCount": 0,
  "horseCardPosition": 0,
  "horseCardPositionIndex": 0
}
```

`arrangeTime=90` 表示摆牌时间配置。客户端应等待所有有效玩家 `hasArranged=true` 或超时后进入比较。

### 5.2 四鬼/鬼牌评估

比较结果中会出现超出普通牌值范围的编码，例如 `60`、`62`、`63`、`66`、`71`，这些是四鬼/鬼牌或内部替换牌编码。不要把它们简单转换为普通 52 张牌。

`evalResult` 示例：

```json
{
  "isWater": false,
  "hasSpecialType": false,
  "frontHand": {"type":"ONE_PAIR","typeId":1,"water":1},
  "middleHand": {"type":"TWO_PAIR","typeId":2,"water":1},
  "backHand": {"type":"FOUR_OF_A_KIND","typeId":7,"water":4},
  "hasHorseCard": true,
  "horseCardPosition": 2,
  "totalWater": 3
}
```

关键字段：

| 字段 | 含义 |
| --- | --- |
| `frontHand/middleHand/backHand` | 三墩牌型 |
| `water` | 单墩水数 |
| `totalWater` | 玩家总水数 |
| `isWater` | 乌龙/摆牌错误标记 |
| `hasSpecialType` | 特殊牌型标记 |
| `hasHorseCard` | 是否命中马牌 |
| `horseCardPosition` | 马牌所在墩位 |
| `isScoop/isScooped` | 全赢/被全赢 |
| `specialWater` | 特殊牌型水数 |

### 5.3 三墩比较

`3923` 的 `compareResults` 会逐对比较玩家的头墩、中墩、尾墩：

```json
{
  "frontWin": true,
  "middleWin": false,
  "backWin": true,
  "frontWater": 1,
  "middleWater": -1,
  "backWater": 10,
  "totalWater": 8,
  "player1Score": 8,
  "player2Score": -8,
  "hasHorseCard": true,
  "isScoop": false
}
```

响应还包括 `totalWaterMap`、`scoreMap`、`scoopRelations`、`homeRunPlayerIds` 和 `specialResults`。这些字段共同构成最终结算，不使用德州或牛牛结算消息。

### 5.4 结算和下一局

流程状态：

```text
DEAL_PERFLOP
 -> ARRANGE_HANDS
 -> COMPARE_HANDS
 -> INNER_END
 -> 下一局
```

客户端会播放三墩比较动画、马牌和水数效果，然后进入 `INNER_END`。牌局结果通常通过 `3923/3924` 和客户端比较结果处理，不单独使用 `DZPK_INNING_RESULT_PUSH`。
