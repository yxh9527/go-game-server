## 6. 一张赏金女王彩票的流程

1. HTTP op=38 获取 roomType=63、gameRoomConfigId=6301、roomIndex=26。
2. HTTP op=45 获取 roomId=18883185，建立 RoomSocket-111 会话。
3. ROOM_LOGIN、SEND_JOIN_ROOM 和 ROOM_TYPE_RESULT 初始化游戏房间。
4. 客户端发送 3702，服务端 3711 返回钱包、票种、面额、倍率和 pendingTickets。
5. 客户端发送 3701，选择 revealMode、faceValue 和 kind=ggl2。
6. 服务端 3713 生成 serialFull 并返回 huMask、中奖计数、倍率、奖级、奖金和新钱包余额。
7. 客户端更新刮票结果和钱包。
8. 客户端可发送 6121 查询记录，服务端 6221 返回票据历史。
