## 权威规则

规则依据原版 holdemGame_zh_cn_Sgay/native/6f/6f38206b-37ea-44b8-b700-ea034522b618.40be8.png 及 native/31/31bba256-bd4a-4181-a81a-43cf7650eba9.2abf8.png。Sgay 包中继承的金花说明图不是本游戏规则。

- 单副 52 张，每人三张。首两张本人可见，第三张下注结束后本人搓牌，随后公开比牌。
- 牌型顺序：豹三（三张 3）> 豹子 > 三公（J/Q/K）> 九点至零点。10/J/Q/K 按 10 点，A 按 1 点；普通点数为总和模 10。同点优先公牌张数，再比较最大单牌的点数、花色。单牌 K 至 A，黑桃>红桃>梅花>方块。
- 普通牌型 ID 为 点数×3+公牌数+1；三公 31、豹子 32、豹三 33。牌值 0..12 为方块 A..K，其后依次梅花、红桃、黑桃。
- 所有人同时选择 1..10 倍底注，金额不得超过实际桌内余额。牌力从高到低依次从底池取不超过本人下注两倍的总返还，直到分完；这是底池玩法，不是庄闲输赢或德州边池。
- 豹三/豹子另外向其他玩家各收一份底注喜钱，按实际可用筹码封顶。税率 taxPercent 采用万分比，样本 500 为正净赢的 5%，可配置 maxTax。赢家净赢、税费和所有余额必须对账守恒。
- 下注只扣一次，重复、跨阶段、非整数、越权及超额请求不扣款。超时下注为一倍，超时亮牌仍走同一验证和结算入口。局中追加带入保留在真实筹码中，不记作本局盈利或税基。

## 消息与可见性

| 请求 | 返回/广播 | 内容 |
| ---: | ---: | --- |
| 3591 | 4406 | {uid,operation:1,operationData:倍率}；广播 currentBetScore、totalBetScore、point、pot |
| 3592 | 3261 | 正常开局请求，仍须满足公共生命周期及开局条件 |
| 3593 | 4408 | 回顾列表：roomId、beginNum、endNum，索引从零开始 |
| 3594 | 4407 | {isShow:true,card:本人第三张实际牌值}；公开三张 holeCardList |

正常顺序：3261 → 3263 DEAL_PERFLOP → 4401 → 3263 XIAN_RAISE → 私发 4400 操作数组 → 4406 → 3263 FLOP → 私发 4401 本人第三张牌 → 4407 → 3263 SETTLE → 4403。默认结算至下一局 5 秒；首次开局等待 3 秒。

4400 的 operation=1，data 包含 isEnable、ante、score、maxMultiple、leftTime。倍率是整数，不能把积分放入 operationData。首发 4401 本人 [牌1,牌2,-1]，其他人/旁观 [-1,-1,-1]；FLOP 只给本人三张真牌。未公开前不能夹带 cardTypeInfo、牌型或第三张牌给其他连接。4407 后才公开；结算必须有三张 handPais、showCards、cardTypeId、score、point、raiseMultiple 和 multipleAnte。

3260 只用于进房/重连/必要座位同步，不可每阶段广播，以免重置原版动画。原版 gameSgay.inningInfo 会从先前 2206 的 point 扣除 xiaZhuData，服务端只在 2206 网络副本补回已下注金额；真实桌内筹码不变。七座旁观视角通过公共 seat-view 投影，2206/3260/4401/4403/4407 与 5003 反向位置使用相同坐标。

## 公共流程

入房默认旁观，主动 5003 占座后使用公共 12 秒带入流程。带入 5001.carryIn 是显示金额，下注 3591.operationData 是倍率。每局结束复用公共准入检查，不足 carryMin 强制站起；已发牌玩家局中离房/站起保留责任筹码，完成当前局再带出。

房间八小时到期停止开新局，当前局完成后回收；无人包括在桌及旁观真人，连续三局后挂起，再有真人进入唤醒。分房、80% 完全满座扩容、概率机器人入离桌、八小时排名和旁观列表均复用公共层。玩法机器人仅位于 games/sgay/robot.js，只接收已知两张牌，不读取第三张或其他人的牌。

## 牌局回顾

原版公共 SgayHistoryModel 继承 HistoryModelBase，SgayHistoryContent 读取 playBackList[0].firstGameList，不能套用牛牛的 dataInfo。每行必需 userName、userIcon、handPais（三张）、cardTypeId、raiseMultiple、multipleAnte、score。

4408 还包含 gameRoomId、roomTypeName=sgya、blind（JSON 字符串，含 ante）、totalNum、beginNum、endNum、excellentGame、isOfflineData。beginNum=-1/endNum=-1 返回最新一局；指定 beginNum=n/endNum=n 精确返回第 n+1 局，无记录则返回空列表，不回退其他局。

列表加载后原版自动发 HTTP op=46 请求 gameRoomId/inningNum，详情必须为 exploitsInfoMsgs 数组，包含 JSON 字符串 inningResults、roundList、inningInfo，以及 gameRoomUnion 和 memberResults。roundList 使用 currentRounds、operationType、uid、nickName、pot。缺少该详情即使列表可见也会卡加载或 JSON.parse(undefined)。开发适配复用已鉴权的 hall → game-server 本地接口，校验 token、可信 agentId、当局参与/旁观权限。房内最多保留 1000 局、八小时 TTL；查询也过滤过期数据，网络副本不得改动历史。
