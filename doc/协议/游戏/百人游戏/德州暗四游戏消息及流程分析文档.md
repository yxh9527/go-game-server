## 3. 核心消息

| 编号 | 消息 | 作用 |
| ---: | --- | --- |
| 6105 | ENTER | 进入百人模式 |
| 6123 | MB_REG_ROOMS_REQ | 注册 roomType=50 房间 |
| 6224 | MB_REG_ROOMS_RES | 返回可监听 roomId |
| 6227 | MB_REGED_ROOM_INFOS | 多桌状态快照 |
| 6228 | MB_SNC_ROOM_STATE | 单桌增量状态 |
| 6204 | GAME_STATE | 通用状态和路单 |
| 6212 | DEAL_CARDS_AND_ODDS | 发牌和下注区赔率 |
| 6229 | MB_ROOM_BET_SETTLE | 开牌及中奖区结算 |
| 6207 | PLAYER_NUM_CHANGE | 百人数量变化 |
| 6124/6225 | MB_UNREG_ROOMS_REQ/RES | 取消房间注册 |
| 6106 | EXIT | 退出百人连接 |

## 5. 状态流程

~~~text
state=0 等待/空闲
 -> state=1 发牌、赔率
 -> state=2 下注快照
 -> state=4 开牌（showdownPokers/showdownTypes）
 -> state=5 结算过渡
 -> state=6 路单和系统统计
 -> state=7 本局结束
 -> 下一局
~~~

## 6. 实现注意事项

1. roomType=19 的普通德州下注消息不等于百人下注请求。
2. 以 roomId + inning 保存多桌、多局状态。
3. 下注区固定为 1–7，但赔率每局动态变化。
4. 6229 的 winningAreas/lostAreas 是结算依据，不能用赔率自行推算。
5. 走势 ways 数组应原样保存，避免截断。
6. -1 表示未公开牌面。

## 7. 退出

~~~text
MB_UNREG_ROOMS_REQ(6124)
 -> MB_UNREG_ROOMS_RES(6225)
 -> EXIT(6106, roomType=50)
 -> HTTP op=54 查询钱包
 -> HTTP op=38 刷新百人房间列表
~~~

## 8. 结论

德州暗四日志实际对应 roomType=50、playMode=4 的“明一公牌”模式。协议主链为：

~~~text
ENTER -> MB_REG_ROOMS_REQ/RES -> MB_REGED_ROOM_INFOS
 -> MB_SNC_ROOM_STATE / DEAL_CARDS_AND_ODDS
 -> MB_ROOM_BET_SETTLE
 -> GAME_STATE -> EXIT
~~~
