## 5. 状态机

~~~text
state=0 等待
 -> state=1 发牌
 -> state=2 下注
 -> state=4 开牌
 -> state=5 结算过渡
 -> state=6 路单统计
 -> state=7 收尾
~~~

6227 的 totalBetsByArea 保存 1–7 下注区总额，ways 保存历史路单，hundredParams.betAreaOdds 保存动态赔率。

## 6. 协议边界

RoomSocket-111 的 DZPK_ACTION_BET_PUSH、BRNN_GAME_STATE_PUSH 属于常规德州桌。百人下注区的下行消息是 6227/6228/6212/6229，本日志未出现明确的百人下注上行请求。

## 8. 结论

德州暗三文件对应的日志实际是 roomType=50、playMode=3 的明二公牌模式。核心流程：

~~~text
ENTER -> 房间注册 -> 6227 快照
 -> 6228/6212 状态和发牌
 -> 6229 中奖区结算
 -> 6204 路单 -> EXIT
~~~
