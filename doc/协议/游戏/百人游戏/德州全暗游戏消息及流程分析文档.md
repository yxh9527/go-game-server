## 4. 核心消息

| 编号 | 消息 | 作用 |
| ---: | --- | --- |
| 6105 | ENTER | 进入全暗百人模式 |
| 6123 | MB_REG_ROOMS_REQ | 注册 roomType=50 |
| 6224 | MB_REG_ROOMS_RES | 返回房间 |
| 6227 | MB_REGED_ROOM_INFOS | 房间快照 |
| 6228 | MB_SNC_ROOM_STATE | 状态和最终开牌 |
| 6204 | GAME_STATE | 通用状态 |
| 6212 | DEAL_CARDS_AND_ODDS | 暗牌占位和赔率 |
| 6229 | MB_ROOM_BET_SETTLE | 结算 |
| 6106 | EXIT | 退出 |

## 5. 状态机

~~~text
state=0 等待
 -> state=1 暗牌发放、赔率
 -> state=2 下注
 -> state=4 开牌结果（showdownPokers）
 -> state=5 结算过渡
 -> state=6 系统统计和路单
 -> state=7 结束
~~~

## 6. 解析注意事项

1. 全暗模式中，-1 是设计上的牌面遮罩，不是数据缺失。
2. 客户端不能在发牌阶段根据牌面计算牌型。
3. 只有 showdownPokers 和 showdownTypes 到达后才能展示结果。
4. winningAreas/lostAreas 由 6229 权威下发。
5. 普通德州 RoomSocket-111 的操作消息与全暗百人下注区无关。
