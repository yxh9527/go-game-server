## 5. 全暗牌局流程

### 5.1 状态机

```text
RUBBING_CARDS
 -> DEAL_PERFLOP
 -> DEAL_LAIZI
 -> GRAB_BANKER
 -> CONFIRM_BANKER
 -> BANKER_SELECT
 -> BANKER_SHOW
 -> XIAN_RAISE
 -> SETTLE
```

### 5.2 全暗发牌

`QZNN_DealCard_PUSH` 样本只返回抢庄准备信息：

```json
{
  "uid": "<uid>",
  "pos": 0,
  "grabBankerPoint": -1,
  "canBanker": false,
  "grabBankerTime": 0,
  "raiseTime": 0
}
```

与看四张玩法不同，全暗场的 `seeCardNo=0`，不在发牌阶段公开 `cardList`。`QZNN_ShowCard_PUSH` 或 `QZNN_Settle_PUSH` 才可能包含完整五张牌和牌型。

### 5.3 抢庄和下注

抢庄广播：

```json
[{"count":2,"playerId":"<uid>"},{"count":3,"playerId":"<uid>"}]
```

定庄消息：

```json
[{"banker":true,"cardIndex":24,"point":5347,"playerId":"<uid>"}]
```

全暗场的 `QZNN_Raise_PUSH` 使用 `[1,6,9,12,15]` 倍数，而不是看四张场的 `[5,10,20,25]`：

```json
{
  "doublePoint": true,
  "bettingMultiples": [1,6,9,12,15],
  "gameStatus": "XIAN_RAISE",
  "bankerId": "<uid>",
  "bettingType": 2
}
```

对应 `QZNN_BetResult_PUSH`：

```json
[{"multiple":5,"multipleAnte":50,"point":3940,"playerId":"<uid>"}]
```

### 5.4 搓牌、牌型和癞子

全暗场的 `QZNN_CuoPaiPhase` 可能为空对象，随后 `QZNN_ShowCard_PUSH` 才公开牌型：

```json
{
  "uid": "<uid>",
  "niuInfo": {
    "niuType": 2,
    "niuJi": 2,
    "belv": 1,
    "cardList": [16,36,9,24,46],
    "cardType": "TWO",
    "combinationsCard": [36,9,24]
  }
}
```

本房间 `laiZi=6`。五张牌、三张组成牌和癞子替换后的牌值应分别保存。

### 5.5 结算

`QZNN_Settle_PUSH` 样本：

```json
{
  "grabBankerPoint": 4,
  "banker": true,
  "xiaZhuData": 4045,
  "niuType": 10,
  "niuJi": 10,
  "combinationsCard": [34,30,31,25,22],
  "handCardListWithLaiZi": [34,25,30,31,22],
  "insurance": 0,
  "uid": "<uid>",
  "score": 4045,
  "point": 8299
}
```

全暗场结算数组包含最终 `handPais`，但这不表示牌局早期曾经公开过牌面。`niuType=10` 表示牛牛，`score/point` 表示输赢和结算后携带分。

## 6. 快速模式和生命周期

`QZNN_DynamicConfig_PUSH` 提供抢庄、看牌、庄家展示、下注和结算时间。全暗场仍然使用快速模式，客户端不能固定写死计时。

生命周期消息包括：

- `3230 CARRY_SCORE_RESULT`：补分。
- `3445 PUSH_CARRYIN_TIPS_USER_LIST`：补分提示。
- `2208 USER_STATE_CHANGE`：座位状态。
- `2213 GAME_TUOGUAN_ACTION`：托管状态。
- `3436 USER_STANDUP_ROOM`：玩家离座。
- `6106 <game>EXIT roomType=52`：辅助连接退出。

## 8. 实现建议

1. 使用 `gameType=24`、`roomType=24`、`gameRoomConfigId=2406`、`playMode=0`、`seeCardNo=0` 识别全暗牛牛。
2. 按 `qznnParams.carryIn=1000`、`ante=10`、`grabBankerPoint=3000` 初始化规则。
3. 全暗场 `QZNN_DealCard_PUSH` 不应期待完整 `cardList`；牌面只在搓牌、亮牌或结算阶段公开。
4. 使用 `[1,6,9,12,15]` 解析闲家倍数，并保留 `doubleRule=3`。
5. 结合 `laiZi=6`、`combinationsCard`、`handCardListWithLaiZi` 计算牌型。
6. 以 `QZNN_BankerAnm` 确认庄家，以 `QZNN_BetResult_PUSH` 确认倍数，以 `QZNN_Settle_PUSH` 确认结算。
7. 不要把全暗场的 `-1` 或缺失牌面当成发牌失败。
8. 生产日志不要输出 token、openId、设备 ID、IP 编码值和完整玩家资料。
