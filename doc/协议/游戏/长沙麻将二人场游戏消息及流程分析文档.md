| type | 上下文 | 解释 |
| ---: | --- | --- |

## 13. 结论

长沙麻将二人场的核心识别条件和消息链路为：

~~~text
roomType=28 / csmj
gameRoomConfigId=2801
playMode=2
maxPeople=2
gameStartNum=2

ROOM_LOGIN(1105/1205)
 -> SEND_JOIN_ROOM(2102)
 -> ROOM_TYPE_RESULT(2201)
 -> ROOM_INFO(2206)
 -> 4209 庄家
 -> 4201 两人快照
 -> 4202 当前回合
 -> 4203 摸牌、出牌、操作提示、副露和胡牌
 -> 3750 客户端过牌/出牌/吃牌等动作
 -> 4213 操作确认
 -> 4211 听牌查询
 -> 4204 两人结算、扎鸟和翻奖
 -> 9212 / 1249 分数与记录
 -> SEND_LEVEL_OUT / USER_LEVEL_ROOM
~~~

实现时应以 roomType=28、roomType=csmj 和 gameRoomConfigId=2801 识别二人场，使用两个 UID 管理玩家，以 4201 保存全量快照，以 4203 驱动增量动作，以 4204 保存两人最终结算。
