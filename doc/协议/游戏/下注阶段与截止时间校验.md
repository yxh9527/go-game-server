# 下注阶段与截止时间校验

2026-11-07。影响 game-server 当前注册的全部 21 个游戏实现；沿用原客户端协议和常驻状态，不重启服务，不增加资金流水或未结算记录。

## 服务端判定

客户端下注必须同时满足目标游戏处于合法下注状态、请求尚未超过截止时间、房间未关闭，以及玩家具有相应操作资格。存在截止时间时使用 now < deadline，等于截止时间即拒绝；NaN、Infinity 等异常截止时间拒绝。判断读取服务端房间与牌局，不接受客户端自报的 state/phase 来开启窗口。

非法时段请求在扣款、筹码、个人下注、区域累计或底池修改前拒绝。多台请求检查目标桌的窗口，不以宿主棋牌桌的阶段替代百人目标桌阶段。热更新沿用原 deadline，不因收到下注或重新加载模块续时。

## 各游戏窗口

| 游戏 | 新下注允许的阶段 |
| --- | --- |
| 普通、暴击、不秀牌德州及比赛共享引擎 | table.phase=playing 且 hand.street 为 BET_PERFLOP/BET_FLOP/BET_TURN/BET_RIVER，当前玩家未弃牌、未全下，且仍在其行动截止时间前。 |
| 普通炸金花 | playing、当前资金动作所属玩家的回合有效、未处于比牌动画暂停、截止时间未到；idle/starting/结算/关闭不接纳资金动作。 |
| 棋牌牛牛各玩法 | 抢庄只在 grab 阶段，下注倍率只在 bet 阶段，截止时间前且未提交过本局下注；发牌、定庄、亮牌及结算不接受下注。 |
| 三公暗一 | stage=bet、未结算、未重复下注且未到截止时间；deal/show/settle 等阶段拒绝。 |
| 常规、赌场二十一点 | 初始下注 4501 只在 BET；保险 4506 只在 INSURANCE；加倍、分牌只在 PLAYER 且属于当前玩家和有效手牌操作窗口。其他状态及超时请求拒绝。 |
| 百人德州、炸金花、牛牛、二十一点、麻将 | 共享 BairenGame 的 BETTING 状态及 phaseEndsAt；所有模式统一拦截非下注状态、过期请求、取消或结算任务进行中及已结算牌局。 |
| 百人百家乐、龙虎斗 | 共用 HundredGame/CardShoeGame，只允许本玩法实际下注状态；禁止展示首牌、开牌、派彩、统计等状态下注，禁止阶段切换及资金任务中下注。 |
| 奔驰宝马、森林舞会、飞禽走兽、麻将转了、趣味捕鱼 | 共用百人 BETTING 与截止时间校验；停注、转盘、派彩、路单等状态均拒绝。 |
| 刮刮乐两款及多台 | 原协议没有倒计时式下注回合，以可购买状态为窗口。关闭、回收、配置停用、离房或场景尚未就绪时不接受新购买；已购票据 SPECIFIED 揭晓不属于新下注，不套用新购买开关。 |
| 麻将三种玩法、十三水四鬼/八鬼 | 不提供客户端直接金额下注入口，客户端只能提交玩法合法动作，资金责任由服务端按玩法阶段计算；不能伪造通用下注消息直接扣增余额。 |

## 客户端与服务端动作边界

离场但本局责任尚未清算的玩家不能重新发送抢庄或下注。既有服务器托管、机器人与超时默认操作仍由内部受控调用完成本局，外部协议不接收 automatic 参数；不能为了拦截迟到请求而让当前牌局永远无法结算。结算派奖、退款及必要的清算并非新下注，不用下注窗口阻断。

本次新公共判断通过 rel 的版本化依赖加载。历史常驻桌首次 tick 才初始化时钟的行为保持；已有时钟从不因请求重置。
