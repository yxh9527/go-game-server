## 5. 游戏流程

### 5.1 摆牌

十三水每个玩家需要将 13 张牌分成三墩：

- 头墩：3 张牌。
- 中墩：5 张牌。
- 尾墩：5 张牌。

日志中的 `<game>undefined` 消息包含：

```json
{
  "uid": "<uid>",
  "hasArranged": true,
  "horseCardPositionIndex": 0,
  "horseCardPosition": 0,
  "roomId": 36612449
}
```

客户端还记录 `arrangedLastTime`、`arrangedCount`、`horseCardPositionIndex` 等摆牌状态。`arrangeTime=90` 是摆牌时间配置。

### 5.2 八鬼牌型评估

`evalResult` 会分别评估三墩：

```json
{
  "isWater": false,
  "hasSpecialType": false,
  "frontHand": {"type":"ONE_PAIR","typeId":1,"water":1},
  "middleHand": {"type":"FLUSH","typeId":5,"water":1},
  "backHand": {"type":"FOUR_OF_A_KIND","typeId":7,"water":4},
  "hasHorseCard": false,
  "isScoop": false,
  "totalWater": 6
}
```

关键字段：

| 字段 | 含义 |
| --- | --- |
| `frontHand/middleHand/backHand` | 三墩牌型评估 |
| `type/typeId` | 牌型名称和编号 |
| `water` | 单墩水数 |
| `totalWater` | 总水数 |
| `isWater` | 是否乌龙/摆牌错误状态 |
| `hasSpecialType` | 是否特殊牌型 |
| `hasHorseCard` | 是否命中马牌 |
| `isScoop/isScooped` | 是否全赢/被全赢 |
| `specialWater` | 特殊牌型额外水数 |

日志牌值可能出现 `52`、`63`、`66`、`71` 等超出普通 52 张牌范围的值，表示鬼牌/癞子或经过牌面替换的内部编码。解析时要使用客户端牌面枚举和 `Resolved` 字段，不能按普通扑克牌数字直接映射。
