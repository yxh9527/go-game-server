## 8. 一局明牌百家乐流程

1. HTTP op=38 查询 gameType=1002、playMode=3 的 roomType=58 档位。
2. HTTP op=45 选择 roomIndex=5，取得 roomId=56394057。
3. ROOM_LOGIN、SEND_JOIN_ROOM、GR_GET_ALL_ROOMS_REQ/RES 建立和同步房间。
4. ENTER_RESPONSE 返回 state、9 区域下注、路单和牌靴快照。
5. state=2 开放下注，客户端发送 BET。
6. BET_RESPONSE 确认个人下注，BET_BROADCAST 广播区域总下注。
7. state=3 停止下注并发牌。
8. state=4 发送 SHOWDOWN_POKERS，直接公开 other、banker 和 showdownPoints。
9. state=6 更新积分、路单和牌靴统计。
10. state=7 收尾，state=0 切换下一局。

## 10. 实现建议和限制

- 使用 roomType + gameRoomConfigId + playMode + roomIndex + roomId + inning 作为唯一上下文。
- 只有 state=2 且倒计时有效时允许 BET。
- 结算先处理 other、banker、showdownPoints，再处理 winningAreas 和积分。
- 牌靴字段以服务端为准，不要前端自行计算剩余牌。
- allPlayerBets 按 areaId 映射，不能依赖数组顺序。
- oddsList 可能包含多个赔付档位，不能简化成单一赔率。
- ROOM_LOGIN 中含用户令牌，正式日志必须脱敏。
