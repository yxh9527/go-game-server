# 会话控制与撤销订阅可回收加载

2026-11-20，Asia/Shanghai。新增 game-server/src/session-control.js、messages.js、core/hundred-lobby.js 三个可回收模块，范围从 192 扩至 195。

会话控制的 sequence、latest、latestKeysByUser、queues、sockets、pendingLogins 和 instanceId 仍保存在原 runtime.sessionControl；registry、原连接、分布式租约服务及已开始的登录任务不替换。

原撤销订阅回调定义在首次 createSessionControl 中，即使回调转调 state.revokeLogin，仍可能持有首次控制器的执行环境。本批将回调移到 shared/session-revocation-listener.js 常驻辅助，仅持有原 state 和 logger，业务更新只替换当前 revokeLogin。老格式订阅首次迁移一次，相同协调服务后续复用同一订阅，不清理原租约或会话。

messages 仍保留原消息号，hundred-lobby 继续从游戏公开快照生成大堂展示；没有改动消息字段、登录配对规则、真实人数或资金行为。百人大堂预览仍按需加载，只读配置时不建桌。

## 验证

新增 test/shared/hot-session-control.test.js 五项，验证：

- 原 socketState、登录 Promise 和序号跨替换保留，同一连接不重复开始登录，任务完成后清理 pendingLogins。
- 老订阅迁移一次；替换后一个订阅调用当前控制器，错误 JSON 不影响原连接，其他 loginId 不撤销当前会话。
- 原 lease claim 等待期间替换控制器，原队列和 claim 只执行一次，仍绑定原连接。
- 百人大堂配置预览不创建真实桌，私有牌堆及余额不泄露，消息号保持。
- 在原连接状态和一个订阅保留期间，中间版本的模块和控制器可回收。

会话控制、分布式会话和新增跨版本综合专项 32 项通过，cache/hot-session-control-scoped.log。600 轮三模块源码变化，共 1800 个编译版本，始终一个订阅，旧版本弱引用回收；最终撤销通知由最新控制器处理，堆净增长 1687184 字节，约 1.61 MiB，cache/hot-session-control-600.log。
