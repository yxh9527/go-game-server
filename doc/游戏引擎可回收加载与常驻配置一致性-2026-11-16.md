# 游戏引擎可回收加载与常驻配置一致性

本轮将 17 个游戏引擎模块加入可回收加载，默认白名单从 54 扩大到 71 个，并修复常驻环境配置／RPC 命名空间的重复加载问题。其余牌型、规则、机器人、历史和资金等未选依赖仍保持原加载方式，完整依赖图回收及长期验收继续列为未完成。

## 接入范围

shared/hot-entry-factory.js 增加显式 collectibleGameEngineFiles：德州、炸金花、牛牛、十三水、三公、麻将、二十一点、百家乐、龙虎、刮刮乐公共引擎、五种百人棋牌引擎，以及 core/bairen-engine.js、core/turntable-engine.js，共 17 个。

核对了顶层变量和引用方向：主要是函数、配置／辅助模块引用，以及适配器工厂返回的函数集合；牌局、下注、结算任务等可变状态仍保存在 table／hand／runtime 中。没有将钱包、RPC 资金操作或未确认资金权益迁到新的模块私有状态，也没有修改这些真实业务引擎文件的玩法代码。

## 常驻模块一致性修复

此前常驻模块只移除 v 和 _hot_source，仍可能保留 link 参数；编译器静态依赖也会向没有内容版本的常驻模块继承 link。环境模块因此可能以另一 URL 被加载第二次，读取不到原 loadEnv 后续更新，RPC 也可能出现独立命名空间。

shared/hot-loader.js 现在在常驻模块分支统一移除上述三个加载参数，连只有 link、没有 v 的地址也处理。静态依赖只对带内容版本的业务模块继承 link，常驻环境及 RPC 与启动代码保持同一个命名空间。

新增回归在隔离进程切换测试环境配置，核对已加载的引擎调用方能读到同一个 env 的当前值，并确认 RPC 命名空间与直接导入严格相同。修改前失败证据为 cache/hot-engine-resident-before.log，没有改动真实启动环境或配置。

## 回收和资金保护验证

新增 test/shared/hot-game-engines.test.js：复制全部 17 个真实引擎，保留引擎间依赖关系，连续实际改变副本 24 轮，共 408 个模块版本。释放中间版本后，以弱引用核对命名空间、新建导出函数、适配器引擎对象及其自有函数均可回收；首轮被主动保留的模块仍可使用，最终 pendingEntries／dependencyWaits 为 0，弱缓存不超过 256。

有些导出只是转发尚未纳入回收的原生辅助函数。这些共享别名仍由其原模块持有，验证不把它们误当作引擎自身新分配的函数，也不据此声称所有辅助依赖已经回收。

既有下注安全、下注阶段、座位净额资金流程、街机转盘、百人庄家和机器人 6 套测试的显式引擎导入改为走新加载路径，原断言保持，**166 项通过**，日志 cache/hot-engine-finance-node.log。覆盖非法金额、阶段保护、绝对盈亏有效下注、带入追加、原结算超时防重、资金顺序等隔离场景；测试不操作真实余额。

专项 **57 项通过**，日志 cache/hot-game-engines-scoped-node.log。Node 全量 **1333 项通过**，日志 cache/hot-game-engines-full-node.log，包含真实剔除 test/cache 的生产副本加载、71 个已选模块各编译一次和 HTTP 检查。全量之后又补强并通过了适配器对象内部函数的 GC 断言，日志 cache/hot-engine-gc-node.log，未再修改生产代码。

## 连续真实引擎副本更新

test/performance/hot-source-change-load.mjs 新增 --entry=engine，复制真实德州引擎、类、入口、目录和处理器。逐次改变引擎副本，通过其真实 texasConf 函数的测试包装字段确认新代码实际用于游戏配置输出；保留的旧游戏实例仍使用原引擎。测试包装仅存在临时副本，不进入真实业务源码或客户端协议。

```powershell
node --expose-gc test/performance/hot-source-change-load.mjs --loader=collectible --entry=engine --revisions=600 --clients=128 --sample-every=50 --output=cache/hot-engine-600.json
```

此次实际改变较大的德州引擎，连带五层模块重建，比此前目录或类更新更重，不能直接作不同负载下的性能改善比较。重载 P99 约 297 ms、最大约 508 ms 仍有明显开销；堆也有增长和 GC 波动。它通过了本次连接／状态检查，但不能视为生产性能、多日负载、所有游戏真钱故障或八小时房间生命周期验收。
