# 牛牛三公真人选择统计接入

本轮继续非德州真人行为统计，接入牛牛（24）和三公（32）的手动选择来源。保留上一批尚未应用的二十一点补丁，合并为 5 文件 Go 包；炸金花补丁此前已核验应用。前端菜单另有 6 文件待应用。

## 规则与实现

原牛牛／三公已把玩家操作、机器人／托管／超时动作区分为 automatic 参数，但结算后没有保留可信来源。现在仅在正常校验接受操作后，在原 hand.players 上记录手动／自动标记；不改变合法操作、倍数、筹码、派彩或时间规则。每个新手牌有行为版本号，热更新前已存在且没有该版本的手牌仍记为未知，不从倍数或结果猜来源。

| 指标 | 牛牛 | 三公 |
| --- | --- | --- |
| 手动下注 | 正常接受的非 automatic 闲家下注 | 正常接受的非 automatic 下注 |
| 下注机会分母 | 只算闲家手数，庄家不算 | 每份可信已结算参与记录 |
| 高于最低档选择 | 手动选中的倍数大于当时合法最低档 | 手动选择大于 1 倍 |
| 手动抢庄选择 | 包括主动选 0 倍不抢 | 不适用 |
| 手动正倍数抢庄 | 手动抢庄且倍数大于 0 | 不适用 |

每种行为按手牌计一次。专用字段包括 betOpportunityHands、manualBetHands／manualBetPercent、aboveMinimumBetHands／aboveMinimumBetPercent；牛牛另有 manualGrabHands／manualGrabPercent、positiveGrabHands／positiveGrabPercent，后两者分母为可信参与手数。

这些玩法没有德州式入池／加注语义，joinPercent、flipManualBetPercent 和 3B／4B 不拿倍数、底注或净输赢填充，继续 --。新专用字段由接口提供，本轮不修改原 Cocos 面板增加显示标签。

shared/native-player-actions.js 只在真实手牌已结算、版本和目标玩家来源完整时归纳布尔事实。game-server/src/core/game-history.js 将该摘要放入原 nativeHistory.seatChoiceBehavior；shared/player-panel.js 生成 behaviorVersion=3 与 seatChoices，MySQL 仅保存统计事实，完整对局详情继续在 go_gp_settlement.log。没有新增金融流水、Redis 缓存或 SQL 原文副本。

生产 profile 检查计数关系：手动下注不超过下注机会，下注机会不超过已知手数，高于最低档不超过手动下注，正倍数抢庄不超过手动抢庄；三公必须全是下注机会且没有抢庄计数。有旧未知记录时，不显示假装覆盖全部历史的比例。机器人稳定随机资料规则不变。
