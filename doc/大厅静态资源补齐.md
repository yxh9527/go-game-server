# 大厅静态资源补齐

大厅小牌资源与 Cocos 游戏资源是不同的目录。游戏内可以正常显示牌，不代表大厅的 l01/img/cards/small 已完整。缺少这些文件会产生连续404；clearGame、普通设置未保存等控制台输出不能据此认定为牌局异常。

在项目根目录 PowerShell 执行以下命令，从原站公共静态路径下载缺图：

    Set-Location D:\project\gogame
    node scripts/sync-hall-card-assets.js --all --source https://lb.zhouerbao.top/

脚本仅访问公共图片路径，不需要 userToken，也不使用登录URL。现有有效文件不覆盖；HTML错误页、非图片内容和截断文件不会保存成图片。逐项失败会列在最终 errors 中，并以非零退出码结束，不能把运行结束当成下载成功。

--all 包含84个资源：69个原版扑克牌预加载资源、二十一点大厅已捕获的4个牌型图标、麻将大厅已捕获的11个牌面（含暗牌-1和白板29）。输出在 static/hall/l01/img，按原URL保留 cards/small 与 room/type/1000/60、62 子目录。单独不带 --all 则只处理69个扑克资源。

离线检查，不下载也不写入：

    node scripts/sync-hall-card-assets.js --all --audit

以最终 missing 和 errors 均为空为准。文件直接部署到 nginx 的大厅静态根，不依赖 client-web，也不需要重启常驻服务。下载后刷新大厅；如旧哈希JS仍被浏览器缓存，使用 Ctrl+F5。当前大厅牌面映射已将扑克-1映射到 card-back-blue.png，不应另外伪造 -1.webp。

2026-10-30最初排查时，301荷官图已从本地同编号原版资源补齐，其余上述大厅图片仍缺失。自动下载因审批模型配置返回404而未执行，随后由用户在本机执行下载。

用户下载后实测：69个扑克资源和4个二十一点图标已存在并正常返回，11个麻将图仍缺失。可离线执行 scripts/restore-hall-mahjong-assets.ps1，从本地原版 resources 的 mj_cards 图集恢复这些图，无需网络或新依赖。按帧名0–8、29映射筒子和白板，使用原版 hold_v_1 底图叠加对应牌面；暗牌-1使用 hold_v_0。旋转打包帧先还原方向，不缩放和重绘牌面，不修改Cocos脚本，不覆盖现有文件。这是本地图集生成的大厅兼容图，不冒充从原站下载的原始大厅PNG。

补齐后验证：--all --audit 返回 expected=84、existing=84，missing/errors均为空。原版Chrome浏览器实际解码84项资源及301荷官图，共85张全部成功；进入百人棋牌原版大厅显示17个房间，网络404和脚本异常均为0。图片回归脚本为 node test/browser/check-hall-images.mjs。相关8项自动化测试通过；离线恢复脚本重复执行created为空、existing=11，不覆盖已存在资源。常驻服务无需重启，刷新浏览器即可读取新图片。
