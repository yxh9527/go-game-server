# 异步游戏 tick 失败进入资金回滚

2026-11-18，Asia/Shanghai。继续检查结算 tick 与权威资金事务的失败边界，修复异步引擎错误被日志吞掉后可能提交中途变化的问题。保留已有修改，不重启服务、不提交代码。

## 问题与修复

create-handler 的普通游戏 tick 分支将异步 game.tick 的拒绝捕获为一条日志，catch 没有继续抛出。即使引擎在等待期间已经改变部分成员筹码、牌局阶段或排入成功消息，外层权威钱包看到的仍是成功结束，于是可能提交部分金融步骤。

game-server/src/create-handler.js 现在在记录 game tick failed 后，如果 runtime.wallet.authoritative 为真，继续抛出原错误。原 Promise.allSettled 收集后，权威事务会走既有恢复流程：恢复牌局／筹码、丢弃尚未发送的成功消息，不调用资金提交。本次 tick 的外层批次仍保留每个房间的完成／失败结果，原日志及不同房间隔离保持。

非权威路径继续原日志处理，不扩展为新的跨房间事务、资金重试、自动恢复或调度机制。同步错误、原 afterRound 拒绝及智能任务分支已按原流程传播，本次针对此前被吞掉的异步普通 tick 拒绝。
